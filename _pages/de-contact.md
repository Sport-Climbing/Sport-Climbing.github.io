# Kontakt

Wenn Sie eine Frage zu einem Beitrag auf Sportklettern haben oder einen Vorschlag, eine wissenschaftliche Quelle oder eine Korrektur, die den Text besser macht, schreiben Sie uns per E-Mail.

## So erreichen Sie uns

**E-Mail der Redaktion:**

[sportclimbing@kavehrs.com](mailto:sportclimbing@kavehrs.com)

## Wobei wir uns freuen, von Ihnen zu hören

- einen Fehler melden oder eine Korrektur zu einem veröffentlichten Text schicken
- auf Bücher, wissenschaftliche Aufsätze und verlässliche Kletterquellen hinweisen
- ein Thema für einen Lehr- oder Forschungsbeitrag vorschlagen
- wissenschaftliche, fachliche oder redaktionelle Zusammenarbeit
- Hinweise und Ideen, wie die Seite besser werden kann

Bitte schreiben Sie, worum es geht. Wenn sich die Nachricht auf einen bestimmten Beitrag bezieht, nennen Sie Titel oder Adresse.
